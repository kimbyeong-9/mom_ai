# 결정로그 01 — Planning Loop 전환율 개선

## 주제

Planning Loop 전환율 개선

## 관련 지표

| 지표 | 목표 방향 |
|------|-----------|
| GP1 | Goal Input → AI Planning 전환율 ↑ |
| GP2 | AI Planning → Result Viewed 전환율 ↑ |
| Planning_LCP | Planning Loop 완료율 ↑ |
| ReSearch_R | 동일 Goal 재탐색 비율 ↓ |

---

## 결정 사항

### 1. 목표 기반 AI Planning 생성

**결정**: 사용자가 자연어로 목표를 입력하면 AI가 단계별 준비 절차를 즉시 생성한다.

**근거**:
- GP1을 높이기 위해 입력 → 결과까지의 마찰을 최소화해야 한다
- 복잡한 온보딩 없이 즉각적인 가치를 제공하는 것이 전환에 유리하다

**제약**:
- 첫 응답 품질이 신뢰를 결정하므로 AI 프롬프트 설계에 집중해야 한다

---

### 2. 상황 맞춤형 준비 절차 제공

**결정**: 목표 유형(청년 지원금 / 해외 / 취업 / 디지털 노마드)에 따라 다른 절차 템플릿을 제공한다.

**근거**:
- 개인화된 결과는 GP2(결과 확인율)를 높인다
- 과도한 개인화 입력 요구는 GP1을 낮추므로 목표 유형 선택만으로 제한한다

**제약**:
- 온보딩은 최대 1단계(목표 유형 선택)로 제한한다

---

### 3. 행동 연결 정보 제공

**결정**: Planning 결과의 각 단계에 실제 행동(링크, 서류명, 기관명)을 직접 표시한다.

**근거**:
- 정보 확인 후 실제 행동으로 이어지지 않는 문제(ReSearch_R)를 줄이기 위해  
  Planning 결과 자체에 행동 가능한 정보를 포함한다

**제약**:
- 링크/기관 정보는 정기적으로 갱신되어야 하므로 데이터 관리 프로세스가 필요하다

---

## 기능 구현 우선순위

1. Goal Input UI (목표 입력 폼)
2. AI Planning API 연동
3. Planning Result 렌더링 (단계별 목록)
4. 행동 연결 정보 표시 (링크, 서류, 기관)

---

## 검증 방법

| 지표 | 측정 방법 |
|------|-----------|
| GP1 | Goal Input 제출 이벤트 / 페이지 진입 이벤트 |
| GP2 | Result Viewed 이벤트 / Planning 생성 이벤트 |
| Planning_LCP | GP1 × GP2 |
| ReSearch_R | 동일 사용자의 동일 Goal 재입력 횟수 |

---

## 개정 — 2026-07 (서비스 범위 축소 + 온보딩 구조 변경)

### 배경

청년지원금/해외/취업/디지털노마드 4개 목표 유형을 범용으로 다루다 보니 "그냥 일반 AI
모델"처럼 느껴진다는 문제가 확인됨. **해외취업 + 디지털노마드** 2개 버티컬로 범위를 좁히고,
이 좁아진 범위 안에서는 더 깊은 온보딩 입력을 받아도 이탈이 크지 않을 것이라 판단함.

### 결정 변경

- **1번 결정("자연어 목표 입력 → AI가 즉시 생성") 개정**: 자유 텍스트 한 줄 대신, 8단계
  구조화된 질문 마법사(`/start`, `AppLayout` 밖의 독립 라우트)로 전환. 국가/지역 → 직군 →
  경력 → 목표 시점 → 비자·체류 자격 → 언어 수준 → 근무 형태 순.
- **2번 결정("온보딩은 최대 1단계로 제한") 폐기**: 자유 대화형 챗봇은 검토했으나 채택하지
  않음 — "입력 완료" 시점이 불명확해 GP1 측정이 흔들리기 때문. 대신 고정 순서 마법사를 택해
  마지막 스텝 제출을 그대로 `goal_input_submitted`로 재사용.
- **3번 결정("행동 연결 정보") 관련 미해결 이슈**: 여전히 LLM이 "확신할 때만" 링크를 채우는
  구조라 실제 행동 연결이 약함. 버티컬별 데이터 큐레이션 또는 실제 검색 그라운딩 중 택일이
  필요 — 아직 미결정.

### 라우팅 변경

- `/start`: 목표 입력 마법사 (사이드바 없음, 홈페이지 CTA 진입점)
- `/planning`: Planning 결과 화면으로 역할 변경 (사이드바 있음, 저장 버튼 포함)
