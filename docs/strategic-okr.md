# Strategic OKR — LifeFlow AI (Mom AI)

## 목적

Planning Loop / Save Loop / Automation Loop / Total Loop 각각의  
전환율을 높이기 위한 전략 방향을 정의한다.

---

## Objective

> 사용자가 Goal을 입력한 순간부터 실제 행동 실행까지 끊김 없이 연결된다.

---

## Planning Loop 전략

**목표**: 사용자가 Goal을 입력하면 즉시 행동 가능한 Planning 결과를 얻는다.

| 전략 | 내용 |
|------|------|
| 즉각 가치 제공 | Goal 입력 후 3초 이내 Planning 결과 노출 |
| 목표 유형 맞춤화 | (2026-07 개정) 해외취업 / 디지털노마드 2개 버티컬에 집중, 8단계 구조화된 질문 마법사로 개인화 |
| 행동 연결 내재화 | 결과 단계마다 실제 행동(링크, 서류, 기관) 포함 — 현재 LLM 자체 판단에 의존해 약함, 데이터 큐레이션/검색 그라운딩 검토 중 |

**핵심 지표 목표**

| 지표 | MVP 목표 |
|------|----------|
| GP1 | 70% 이상 |
| GP2 | 80% 이상 |
| Planning_LCP | 56% 이상 |

---

## Save Loop 전략

**목표**: Planning 결과를 자산으로 저장하고 언제든 재진입한다.

| 전략 | 내용 |
|------|------|
| 저장 CTA 최적화 | 결과 스크롤 25% 시점 이후 고정 노출 |
| 자산 인식 강화 | 저장된 플랜을 "내 플랜" 형태로 브랜딩 |
| 재진입 경로 단순화 | Saved 페이지를 홈 네비게이션에 노출 |

**핵심 지표 목표**

| 지표 | MVP 목표 |
|------|----------|
| SP1 | 50% 이상 |
| RP1 | 60% 이상 |
| Save_LCP | 50% 이상 |

---

## Automation Loop 전략

**목표**: 저장된 플랜에서 반복 행동을 자동화로 연결하고 실행한다.

| 전략 | 내용 |
|------|------|
| 자동화 인지율 향상 | 플랜 단계 내 인라인 추천으로 자연스러운 노출 |
| 실행 마찰 제거 | (2026-07 개정) n8n 기반 지속 실행 — 1회성 실행이 아니라 연결해두면 계속 대신 찾아봐주는 구조 |
| 자동화 유형 제한 | (2026-07 개정) 채용/원격구인 모니터링 → 비자·체류 마감일 리마인더 순으로 우선순위 재정의, 문서정리는 기존 로직 유지 |

**핵심 지표 목표**

| 지표 | MVP 목표 |
|------|----------|
| AP1 | 40% 이상 |
| AP2 | 70% 이상 |
| Automation_LCP | 28% 이상 |

---

## Total Loop 전략

**목표**: Planning → Save → Automation의 연결 흐름을 사용자가 자연스럽게 경험한다.

| 전략 | 내용 |
|------|------|
| 흐름 연결 | Planning 결과 → 저장 → 자동화 추천을 끊김 없이 연결 |
| ReSearch_R 감소 | 저장 + 자동화로 재탐색 필요 제거 |
| Total_LCP 기준선 | MVP 출시 2주 이내 데이터 수집 후 목표 설정 |

---

## OKR 우선순위

```
1. Planning Loop 전략 → GP1, GP2 확보
2. Save Loop 전략     → SP1, RP1 확보
3. Automation Loop 전략 → AP1, AP2 확보
4. Total Loop 관측    → Total_LCP 기준선 수립
```
